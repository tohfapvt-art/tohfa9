# Tohfa — Gifting, Beautifully Considered

Curated gifting and bespoke gift hampers designed to turn meaningful moments into lasting memories.

## ✨ Features
- **Curated Collections**: Hampers for birthdays, weddings, anniversaries, and corporate celebrations.
- **Interactive Experience**: 3D gift installations, dynamic animations, and luxury aesthetics.
- **WhatsApp Concierge & Enquiry Form**: Instant WhatsApp chat integration and lead management.
- **Custom Branding & Styling**: Responsive luxury purple & gold theme with SVG favicons and social badges.

## 🚀 Getting Started

To run the project locally:

```bash
node outputs/dev-server.js
```

Then visit [http://localhost:4173](http://localhost:4173) in your browser.
